# Rilevanza separata dalla Versione

Lo smistamento in dashboard (In evidenza / Novità / Digest) e la decisione di generare una sintesi
AI dipendono dalla **Rilevanza**, non dal tipo SemVer della **Versione**. Molte tecnologie non
seguono il SemVer (TypeScript, Python, Node LTS, librerie 0.x, pre-release), quindi ogni
Tecnologia ha una Strategia di classificazione, correggibile a mano per singola Release.

Le spec CSS/W3C, che non hanno versioni, sono fuori dall'MVP: entreranno come nuovo tipo di fonte
con una propria strategia, senza cambiare il modello.
