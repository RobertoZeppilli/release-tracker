release-notes github.com/vitejs/vite · 31 lines
  1. # Vite 6.0
  3. Vite 6 is the most significant major since Vite 2.
  4. The ecosystem is ready to move forward together.
  6. ## Environment API (experimental)
  7. Frameworks can now run code in environments closer to production.
  9. ## Node.js support
  10. Vite 6 supports Node.js 18, 20, and 22+. Node.js 21 support is dropped.
  11. ## resolve.conditions
  12. The default value of resolve.conditions has changed; custom values replace the defaults.
  13. Use defaultClientConditions and defaultServerConditions to extend them.
  15. ## JSON stringify
  16. json.stringify: 'auto' is now the default and only stringifies large JSON files.
  17. Set json.stringify: false to restore the previous behaviour.
  19. ## Sass
  20. The modern API is now used by default for Sass. The legacy API is still available.
  21. Set css.preprocessorOptions.sass.api: 'legacy' while migrating.
  23. ## Library mode
  24. In library mode the CSS file is now named from package.json "name" instead of style.css.
  25. Configure build.lib.cssFileName to change it.
  27. ## HTML asset references
  28. More elements are processed, including <video poster> and <meta content>.
  30. ## PostCSS
  31. postcss-load-config v6 loads TypeScript configs with tsx or jiti.
